# Document Q&A (RAG)

Ask questions about your PDF and TXT documents. Answers are generated by Gemini
using only the content of your files, with sources shown. If the answer is not
in the documents, the assistant says so instead of guessing.

## Setup (Windows, PowerShell)

1. Install Python 3.12 (the version this project was tested with).
2. Create and activate a virtual environment:

       python -m venv venv
       venv\Scripts\activate

   If PowerShell blocks the script, run once:
   `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

3. Install dependencies:

       pip install -r requirements.txt

4. Copy `.env.example` to `.env` and put your Google AI Studio API key in it:

       GOOGLE_API_KEY=your_api_key_here

## Usage

1. Put your PDF or TXT files into the `data` folder.
2. Index them (only new files are processed):

       python main.py index

3. Ask questions:

       python main.py ask

Type `exit` to quit.

## Settings

All settings (models, chunk size, number of retrieved chunks) are in
`src/config.py`.

## Notes

- Scanned PDFs without a text layer are not supported (they need OCR).
- The free Gemini tier has request limits. If you see a rate-limit message,
  wait or switch to a paid key.

## Structure

    main.py          entry point
    src/config.py    settings
    src/loaders.py   file loading and chunking
    src/vectordb.py  vector database (ChromaDB) and indexing
    src/qa.py        question answering
    data/            your documents
